# Nidaan - Patient Case Taking Software

### Digital Patient Intake & Doctor Consultation System

Nidaan is a digital healthcare solution that streamlines patient registration, medical intake, document submission, OCR-based information extraction, emergency handling, and doctor consultation.

## 🎯 Key Features

- ABHA number-based patient identification
- Digital medical questionnaire for structured patient intake
- Chief Complaint (CC) and HPI collection
- Medical, Family & Social History
- Multiple medical document uploads
- Emergency detection with immediate questionnaire termination
- Automatic transfer of emergency patient information to the doctor dashboard
- Doctor consultation queue with emergency alerts
- Patient profile and intake summary
- Diagnosis and prescription workflow

## 🛠️ Technology Stack

**Frontend:** React, TypeScript, Vite  
**Backend:** Node.js, Express, Prisma  
**Database:** PostgreSQL  
**Deployment:** Docker
